# MauiWebView

## Project Overview
MauiWebView is a cross-platform application built with .NET MAUI, designed to showcase the integration of web content within a native app using the WebView component.

## Features and Characteristics
- **Cross-platform Support:** Runs on Android, iOS, Windows, and Mac Catalyst.
- **Modern Framework:** Built with .NET10.0 for improved performance and compatibility.
- **WebView Integration:** Displays web pages and interactive web content directly inside the app.
- **Responsive UI:** Adapts to different device sizes and platforms for a consistent user experience.
- **Native Experience:** Combines native controls with web technologies for seamless interaction.
- **Simple Architecture:** Easy to understand and extend for developers familiar with .NET MAUI.

## Supported Platforms
- Android
- iOS
- Windows
- Mac Catalyst

## Technologies Used
- .NET MAUI
- C#
- XAML
